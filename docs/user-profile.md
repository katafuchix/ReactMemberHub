# ユーザープロフィールページ

Issue: #5 プロフィールページの作成

他のメンバーが閲覧できる公開プロフィールページ。自分自身のプロフィールも同じページで確認できる。
プロフィールの編集は従来どおり `/profile`（要ログイン）。

## 画面

| パス | 画面 | 認証 |
|---|---|---|
| `/users/:id` | 公開プロフィール（`pages/UserProfile.tsx`） | 不要（投稿の表示範囲がログイン有無で変わる） |
| `/profile` | 自分のプロフィール編集（`pages/Profile.tsx`） | 必須 |

### `/users/:id` の表示内容

- アイコン（未設定時は表示名の頭文字）
- 表示名、有料会員バッジ（`membership: premium` のみ）
- 登録日
- 自己紹介（未設定時は「自己紹介はまだありません」）
- そのユーザーの投稿一覧（新しい順、件数つき）
- 自分のページ（`/users/<自分のid>`）の場合のみ「プロフィールを編集」ボタン（`/profile` へ）

存在しない ID / 不正な ID の場合は「ユーザーが見つかりません」を表示する。

### 導線

| 起点 | 遷移先 |
|---|---|
| フィードの投稿カードの作者名 | `/users/:id` |
| 投稿詳細の作者名 | `/users/:id` |
| 投稿詳細のコメント投稿者名 | `/users/:id` |
| `/profile` の「公開プロフィールを見る」 | `/users/<自分のid>` |

フィードのカードは全体が `<Link>` のため、作者名は入れ子の `<a>` を避けて `onClick` で遷移させている。
退会済み（作者が存在しない）の投稿は「退会ユーザー」と表示し、リンクにはしない。

## API

### `GET /api/users/:id`（既存）

公開プロフィールを返す。`profileUser`（`server/models/User.ts`）で整形するため **email / role は含まない**。

```json
{ "user": { "id": "...", "displayName": "...", "avatarUrl": "", "bio": "", "membership": "free", "createdAt": "..." } }
```

| ステータス | 条件 |
|---|---|
| 200 | 取得成功 |
| 400 `invalid_id` | ObjectId として不正 |
| 404 `not_found` | ユーザーが存在しない |

### `GET /api/users/:id/posts?page=1&limit=20`（新規）

指定ユーザーの投稿一覧。`optionalAuth`。

- 未ログイン: `visibility: public` の投稿のみ
- ログイン済み: `members` 限定投稿も含む（`GET /api/posts` と同じルール）
- 新しい順。`limit` は最大 50
- レスポンスは `GET /api/posts` と同形式: `{ items, total, page, limit, hasMore }`
  - `items[].author` は `displayName avatarUrl membership` を populate

| ステータス | 条件 |
|---|---|
| 200 | 取得成功（投稿 0 件なら `items: []`） |
| 400 `invalid_id` | ObjectId として不正 |
| 404 `not_found` | ユーザーが存在しない |

## 公開範囲の考え方

- 公開されるのは `profileUser` のフィールドのみ（表示名・アイコン・自己紹介・会員種別・登録日）。
- メールアドレス・ロール・認証状態は他人には返さない。
- 投稿は既存の `visibility` ルールに従う。プロフィール経由でも会員限定投稿は未ログインに見えない。

## 制限事項（PoC）

- 投稿一覧はページネーション UI なし（API は `page` / `limit` 対応済み。画面は先頭 20 件のみ）。
- フォロー、ブロック、プロフィールの非公開設定は未実装。
- 管理者による他ユーザーのプロフィール編集は未実装。

## 動作確認手順

1. `npm run seed` → `npm run dev:full`
2. 未ログインでフィードの作者名をクリック → `/users/:id` で公開投稿のみ表示されること
3. ログイン後、同じページで会員限定投稿も表示されること
4. `/profile` の「公開プロフィールを見る」から自分のページを開き、「プロフィールを編集」が出ること
5. `/users/000000000000000000000000` → 「ユーザーが見つかりません」
